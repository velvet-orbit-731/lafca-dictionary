# 第2回「文字と発音」台本（第1稿）

- **想定尺**：約10分
- **扱う範囲**：文法書1.1〜1.3（回割り案の第2回）。新しい用語は「音節」「強勢」。
- **表記の約束**：第01回と同じ。この回では次の3点も守る。
  - ラフカ語の文字は声で名前を呼ばず、「山の付いた z」（ž）、「点が二つの a」（ä）のように形で指す。点や山の付かない文字は英語の読みで呼んでよい（r＝アール）。
  - カナは音の目安として【画面】にだけ出す。単語をまるごとカナにはしない（子音の後に母音を足した形になってしまうため）。一つの音か、子音＋母音のひとまとまりまでにする。
  - 発音記号は使わない。

---

## 1. オープニング

【画面】タイトル「ラフカ語文法ゆっくり解説　第2回　文字と発音」

霊夢：ゆっくり霊夢よ。
魔理沙：ゆっくり魔理沙だぜ。
霊夢：前回は、「タヌキを」の形が三つもあって驚いたわね。
魔理沙：文法に入る前に、今日は文字と発音をやっておくぜ。
霊夢：私たちの声じゃ、ラフカ語は読めないって言ってたわよね。
魔理沙：ああ。だから今日は、口の動きと、近いカナで説明する。

【画面】注意書き「カナは音の目安です」

魔理沙：カナはあくまで目安だ。ぴったり同じ音ではないからな。

## 2. 母音は八つ

魔理沙：まずは母音から。ラフカ語の母音は八つある。

【画面】a　e　i　o　u　｜　ä　ö　ü（右の三つを光らせる）

霊夢：五つは日本語と同じね。残りの三つには点が付いてる。
魔理沙：この点が二つ付いた三つが、日本語にはない母音だ。
魔理沙：その前に、いつもの五つのうち一つだけ注意がある。

【画面】u：唇を丸く突き出す（口の図）

魔理沙：u は、唇をしっかり丸めて「ウ」と言うんだ。
霊夢：日本語のウより、口をとがらせる感じ？
魔理沙：そうだ。じゃあ、点の付いた三つにいくぜ。

【画面】ä：「エ」の口を、もっと大きく開く／英語の cat の a に近い

魔理沙：点が二つの a は、「エ」の口をもっと大きく開いた音だ。
霊夢：英語の cat の a みたいな？　アとエの間の。
魔理沙：それがいちばん近いな。

【画面】ü：「イ」の舌のまま、唇を丸める

魔理沙：点が二つの u は、「イ」と言いながら、唇だけ丸める。
霊夢：……イのつもりで、口はウ。むずかしいわね。

【画面】ö：「エ」の舌のまま、唇を丸める

魔理沙：点が二つの o は、「エ」と言いながら、唇を丸める。
霊夢：同じやり方ね。イで丸めると点の u、エで丸めると点の o。
魔理沙：そのとおり。点が付くと、舌の位置が前寄りになるんだ。
霊夢：じゃあ、点はただの飾りじゃないのね。
魔理沙：ああ。単語の形が変わると、a が点の付いた a になることもある。
霊夢：前回の「人を」がそうだったわね。
魔理沙：よく覚えてるな。それは第4回でやるぜ。

【画面】最初から点の付いた単語：äm（家）　müq（汚い）　nö（〜ない）

魔理沙：もちろん、最初から点の付いた単語もたくさんあるぞ。

【画面】日本語：おばさん／おばあさん（長さで別の言葉）
　　　　ラフカ語：音の長い・短いで言葉を区別しない

魔理沙：それから、ラフカ語は音の長い・短いを区別しない。
霊夢：日本語だと「おばさん」と「おばあさん」は別人よね。
魔理沙：ラフカ語には、そういう区別がないんだ。

## 3. 子音は二十二

魔理沙：次は子音だ。子音は全部で二十二ある。

【画面】子音の一覧（白＝英語とほぼ同じ読み、黄色＝注意する文字）
　白：p　t　b　d　g　m　n　f　v　s　z　l　r　w
　黄色：c ／ k　h　q　j　š　ž　č　pf

霊夢：白い文字は、英語と同じ読み方でいいの？
魔理沙：だいたいな。ただし g は、いつも「ガ行」の音だ。
魔理沙：英語の orange の g みたいに、ジにはならない。
魔理沙：f と v は英語と同じで、下唇に上の歯を当てて出す。
霊夢：日本語の「フ」とは違うのね。
魔理沙：それと、r と l は別の音だ。
魔理沙：英語でも、right と light は違う単語だろ？
魔理沙：じゃあ、黄色の文字を一つずつ見ていくぜ。

### c と k

【画面】c と k はどちらも「ク」の音
　　　　k は単語の最後だけ。それ以外は c
　　　　penk（5）→ pencet（5番目）

魔理沙：まず c と k。どちらも同じ「ク」の音だ。
霊夢：同じ音なのに、文字が二つあるの？
魔理沙：k を使うのは単語の最後だけ。それ以外は全部 c で書くんだ。
魔理沙：たとえば「5」は、k が単語の最後にあるだろ。
魔理沙：「5番目」は後ろに文字が続くから、c になるんだ。
霊夢：なるほど、音は変わらないのね。

【画面】英語：city（c＝ス）／ラフカ語：c はいつも「ク」

魔理沙：ああ。それと英語だと、city の c は「ス」になるよな。
魔理沙：でもラフカ語の c は、e や i の前でも、いつでも「ク」だ。
霊夢：了解。c を見たら「ク」、ね。

### h

魔理沙：次は h。これは、後ろの音によって二通りに聞こえる。

【画面】h の後ろが i・e・ä・ü・ö・j　→　「ヒ」の頭の音
　　　　それ以外（a・o・u、子音、単語の最後）　→　喉の奥を強くこする「ハ」

魔理沙：前寄りの母音の前では、日本語の「ヒ」の頭の音になる。
魔理沙：それ以外では、喉の奥を強くこすった「ハ」になるんだ。
霊夢：前回の「狩る」と「狩った」にも h があったわね。

【画面】ihas（h の後ろが a → 喉の奥の「ハ」）
　　　　ihit（h の後ろが i → 「ヒ」の頭）

魔理沙：いいところに気づいたな。「狩る」は喉の奥の音、「狩った」は「ヒ」の音だ。
霊夢：同じ文字なのに、音が違うのね。
魔理沙：でも、別々に覚えなくていい。後ろの音を見れば決まるからな。

### q

【画面】英語：queen（q の後ろに u）／ラフカ語：q だけで一つの音

魔理沙：次は q。英語だと、q の後ろにはたいてい u が来るよな。
魔理沙：ラフカ語の q は全然違う。「ガ」を、舌を付けずにこすって出す音だ。
霊夢：ガなのに、止めないの？
魔理沙：そう。喉の奥で、ガをこすり続ける感じだ。
魔理沙：人や地域によっては、うがいのような喉の奥の音にもなる。

【画面】qaren（奪う）　deqa（雨）　taq（6）
　　　　単語の最初・途中・最後のどこにでも出る

霊夢：r とは違うの？
魔理沙：違う。r とは、はっきり区別するぜ。

### j

【画面】j ＝ ヤ行（ja＝ヤ、jo＝ヨ）／ jil（年）

魔理沙：j は「ヤ行」の音だ。英語の Japan の「ジャ」とは違う。
霊夢：ラフカ語の読み方だと、Japan はヤパンになっちゃうのね。
魔理沙：まあ、そういうことだな。

### 山の付いた三つと pf

【画面】š ＝「シ」の頭（シャ・シ・シュ・シェ・ショ）
　　　　ž ＝「ツ」の頭（ツァ・ツィ・ツ・ツェ・ツォ）
　　　　č ＝「チ」の頭（チャ・チ・チュ・チェ・チョ）
　　　　例：šin（石）　žuser（父）　čeq（空）

魔理沙：次は、山の付いた三つの文字だ。
魔理沙：山の付いた s は「シ」、z は「ツ」、c は「チ」の頭の音になる。
霊夢：シ・ツ・チ。どれも日本語にある音ね。
魔理沙：ただ、どの母音とも組めるのが日本語と違う。「ツァ」や「ツェ」もあるぜ。
霊夢：「ツァ」はあまり使わないけど、言えなくはないわね。

【画面】pf ＝ 唇を閉じたところから、すぐ下唇に歯を当てて息を出す／ pfe（4）

魔理沙：最後に pf。これは二文字で一つの音だ。
魔理沙：「プ」と「フ」を、一息でまとめて出す感じだな。
霊夢：プとフを一回で……。唇がいそがしいわね。

## 4. 音節：子音は三つまで並ぶ

魔理沙：さて、ここからが本番だ。ラフカ語は、子音がたくさん続く。

【画面】sprengen（締める）

霊夢：うわ、最初に子音が三つも並んでる。
魔理沙：日本語だと、子音の後には必ず母音が付くよな。

【画面】日本語：ス・プ・リ・ン・グ（五つ）／英語：spring（ひとかたまり）

霊夢：英語の spring も、カタカナで書くとスプリングね。
魔理沙：でも英語では、spring はひとかたまりで発音する。
魔理沙：この、母音一つを中心にしたまとまりを「音節」というんだ。

【画面】用語「音節」＝母音一つと、その前後の子音のまとまり

魔理沙：ラフカ語では、一つの音節の前にも後ろにも、子音を三つまで置ける。

【画面】sprengen ＝ spren ／ gen（2音節）
　　　　disprinct（締められた）＝ di ／ sprinct（2音節）
　　　　sprinct ＝ 子音三つ＋母音＋子音三つ

魔理沙：「締められた」の後ろの音節は、子音三つ、母音、子音三つだ。
霊夢：これ、ほんとに一つのまとまりなの？
魔理沙：ああ。読むときのコツは、子音の間に余計な母音を足さないことだ。
霊夢：日本人には、それがいちばん難しそうね。
魔理沙：でも数え方は簡単だぜ。母音を数えれば、それがそのまま音節の数になる。
霊夢：「締める」は母音が二つだから、二音節ね。
魔理沙：そのとおり。一つの音節に、母音は一つだけなんだ。
霊夢：じゃあ、日本語の「あい」みたいに母音が続くこともないの？
魔理沙：一つの音節の中ではな。母音がくっつきそうなときは、間に別の音を挟む。
魔理沙：それは、第5回でやるぜ。

【画面】単語の初め：p・t・k などの音 → m・n → l・r → w・j → 母音
　　　　（右へ行くほど、よく響く音）
　　　　s と山の付いた s は、いちばん前に足せる
　　　　例：sprengen（締める）　šwet（世界）　hlen（小さい）

魔理沙：子音の並び方にも決まりがある。
魔理沙：単語の初めでは、母音に近づくほど、よく響く音が来るんだ。
霊夢：じゃあ、l や r の後に p が来ることはないのね。
魔理沙：そう。音節の終わりはその逆で、母音から離れるほど響かない音になる。

【画面】音節の終わり：-nd　-nt　-st　-rt　-nk など
　　　　例外：čask（山羊）の -sk

魔理沙：まあ、読むだけなら「子音の間に母音を足さない」を守れば十分だ。

【画面】fett（森）　ross（大きい）　tonn（太陽）

魔理沙：あと、同じ子音を二つ重ねて書く単語もある。
魔理沙：重なった子音は、少し長めに出すんだ。

## 5. 強勢：後ろから二つ目を強く

魔理沙：最後に、単語のどこを強く読むか。これを「強勢」という。

【画面】用語「強勢」＝単語の中で強く読むところ

霊夢：英語のアクセントみたいなもの？
魔理沙：そう。でも英語と違って、単語ごとに覚えなくていいぜ。
魔理沙：ラフカ語は、後ろから二つ目の音節を強く読む、と決まってるんだ。

【画面】tí・nor（タヌキを）　í・has（狩る）　í・hit（狩った）
　　　　（強く読む音節を大きく表示）

霊夢：前回の単語はどれも二音節だから、前を強く読むのね。
魔理沙：そういうことだ。一音節の単語なら、そこを強く読むだけだな。
魔理沙：じゃあ、これはどうだ？

【画面】žú・ser（父）　→　žu・sá・ren（父の）

霊夢：後ろが長くなったら、強く読むところがずれたわ。
魔理沙：後ろから数えるから、単語が長くなると位置がずれるんだ。
魔理沙：ただし、例外が少しある。

【画面】強く読まない小さい単語（次の単語にくっつけて読む）
　　　　例：nö（〜ない）

魔理沙：「〜ない」みたいな短い単語は、強く読まずに次の単語にくっつけて読む。
霊夢：日本語の「は」や「を」を強く読まないのと似てるわね。
魔理沙：ほかの例外は、出てきたときに説明するぜ。

【画面】注意：強勢の印（í など）は説明用。ふだんの綴りには付けない

魔理沙：あ、この印は説明用だ。ふだんの綴りには付けないぜ。

## 6. 練習

魔理沙：じゃあ練習だ。今日の決まりで、この四つを読み解いてくれ。

【画面】žuser（父）　sprengen（締める）　šwet（世界）　penk（5）／ pencet（5番目）

霊夢：一つ目は、父。山の付いた z だから「ツ」の頭ね。
霊夢：母音は u と e の二つ。二音節だから、前を強く読む。

【画面】žú ／ ser　「ツ」の頭＋u（強く）／ s＋e＋r

魔理沙：完璧だ。最後の r の後ろに、母音を足さないようにな。
霊夢：二つ目は、締める。子音三つで始まって、母音は e が二つ。
霊夢：二音節だから前を強く。g はガ行だから、「ジェ」じゃなくて「ゲ」ね。

【画面】sprén ／ gen　g＝ガ行

魔理沙：いいぞ。最初の三つの子音の間に、母音を入れないのがコツだ。
霊夢：三つ目は、世界。山の付いた s で「シ」の頭、それから w。
霊夢：母音は e だけだから、一音節ね。

【画面】šwet（1音節）　「シ」の頭＋w＋e＋t

魔理沙：そうだ。日本語みたいに分けずに、ひとまとまりで言うんだ。
霊夢：四つ目は、5と5番目。5は最後が k。
霊夢：5番目は後ろに続くから c になってるのね。音はどっちも「ク」。
魔理沙：英語の癖で、c の後ろの e を「セ」と読まなかったな。
霊夢：c を見たらク、でしょ？　さっき聞いたもの。
魔理沙：じゃあ、5番目はどこを強く読む？
霊夢：母音が二つで二音節だから、前のほうね。

【画面】penk（1音節）／ pén ／ cet（2音節）　k も c も「ク」

魔理沙：正解だ。これで、ラフカ語の文字はひととおり読めるな。

## 7. まとめ

魔理沙：じゃあ、今日のまとめだ。

【画面】まとめ
　・母音は八つ。点の付いた ä・ü・ö は日本語にない。音の長い・短いは区別しない
　・c と k はどちらも「ク」。k は単語の最後だけ。h は後ろの音で二通りになる
　・q はガをこする音、j はヤ行、š・ž・č はシ・ツ・チの頭の音
　・一つの音節には、母音一つと、前後に子音三つまで。子音の間に母音を足さない
　・強勢は、後ろから二つ目の音節

霊夢：子音が続くのは大変だけど、強く読む場所が決まってるのは助かるわ。
魔理沙：次回から、いよいよ文法だ。第3回は、名詞の「性」と単数・複数だぜ。
霊夢：名詞に男とか女とかがある、って話ね。
霊夢：それじゃあ、ご視聴ありがとうございました！
魔理沙：またな！
