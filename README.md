# ラフカ語辞書

[ウェブ辞書](https://velvet-orbit-731.github.io/lafca-dictionary/)

このリポジトリの `dictionary.json` が語彙・語義・語形・関連語の唯一の正本です。ウェブ画面からの保存は、全語彙と表示用HTML・版情報を同時に更新します。既存の項目IDは維持します。

`index.html` は表示用、`version.json` は件数とハッシュ、`ラフカ語文法.md` は文法、`収録と未確定事項.md` は生成時点の報告です。`dictionary.json` の `metadata` は語源・対応語などの設計注記で、保存済み語形を上書きするデータではありません。

ローカルの辞書Markdownと、基礎語彙に別の編集差分を重ねる管理は廃止しました。語彙の追加・変更はこのウェブ辞書に保存します。
