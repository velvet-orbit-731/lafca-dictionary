# ラフカ語（Lafca）資料

アルディーク語族・東アルディーク語派に属する架空言語、ラフカ語の文法・辞書・制作ツール。アルディア語（中央アルディーク語派）の姉妹語で、相互理解はできない。

文法規則は文法書に集約する。最新のウェブ辞書の語義・性・曲用型・個別の登録形だけでなく、構文注記・用例も読み、本文の用法説明に反映する。旧文法書に説明がないことを、現在の用法が未規定である根拠にはしない。資料間で異なっていた格支配と規則の適用範囲は、文法書9.5に統一した規則と根拠を示す。系統・音変化の資料は歴史的な説明を扱い、未確定の祖形や変化順序から登録済みの語形を自動的に置き換えない。数詞の品詞・一致・格支配・加算・序数は文法7章に集約する。

## 更新する

文法書・語彙・資料・ツールはすべてこのリポジトリにある。語彙は直下の `dictionary.json` が全項目を持ち、[ウェブ辞書](https://velvet-orbit-731.github.io/lafca-dictionary/)の画面での保存もこのファイルを更新する。ローカルの辞書Markdownは廃止・削除した。

生成されたHTMLや `data.json` は直接編集しない。Python 3.9以降とNode.jsを用意し、リポジトリ直下で実行する。

```sh
git pull --ff-only
python3 tools/check.py --build
python3 辞書/export_pages.py
```

画面を変更した場合は、Playwrightを利用できる環境で `--ui` も付ける。資料とコードの役割、個別検査、公開用の書き出し手順は [保守ガイド](保守ガイド.md) を参照。

## 設計の前提

- 8母音・22子音、最大CCCVCCCの音節構造。/k/ は語末だけ k、それ以外は c と綴る。
- 名詞は三性・五格、代名詞は対格も持つ。文法性、曲用型、数の制限を区別する。
- 名詞の曲用と動詞の時制に母音交替があり、屈折と不変化小辞を併用する。
- 古い複合語は継承形、新しい複合語は現代の構成語を使う。どちらも続け書きし、後部に従って曲用する。
