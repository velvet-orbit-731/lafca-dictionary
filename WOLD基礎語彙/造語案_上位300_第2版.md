# WOLD 基礎語彙 上位300の造語案（第2版）

作成日：2026-10-29。状態：**採用・ウェブ辞書登録済み**（2026-10-29、§5 を作者がすべて承認。92項目）。 第1版は作者の指示で棄却した（結論を先に決めて根拠を後から探していたこと）。本版では WOLD の41言語の分布を先に調べ、それを目安にしながら、ラフカ語としてどこを一語で兼ね、どこを分けるかを一語ずつ決めた。2026-10-29 改訂：範囲を割合の線引き（過半数なら一語）だけで決めていた版を、作者の指摘（意味論的に平均値をとる言語は存在しない）を受けて改めた。語彙の正本は[ウェブ辞書](https://velvet-orbit-731.github.io/lafca-dictionary/)（2026-10-29 時点 947項目）。

[突き合わせ表](突き合わせ表_上位300.md)で欠けていた90項目（× 87、◇ 3）のうち、尋（◇）を除く89項目に語を当てる。シラミ（頭・体）を一語にまとめ、嫁・婿から前提にされる舅・姑を加え（姑は夫の母と妻の母に分ける）、「どれ」は相関詞の体系に置いたので、**92項目**になる（継承44、東語派固有の語根44、既存語からの派生2、相関詞2）。

## 0. 資料と手順

1. **WOLD の41言語。** 各項目について、各言語の最初の語形を「単純語（分析できない語）／派生／複合／句／借用」に分けて数えた（CLDF 版 lexibank/wold の `forms.csv`。Analyzability と Borrowed の欄）。
2. **兼用。** 同じ言語の同じ語（同じ Word_ID）が二つの項目に載っている言語を数え、その項目の言語数 n で割った。WOLD の41言語で少数でも、世界の諸言語に実例があるかは CLICS⁴ の語族数で確かめた。
3. **アルディア語辞書。** 由来欄で、単純語（元から・単語生成機・オリジナル）か、複合語・派生語・借用語かを確かめた。
4. 語形はアルディア語からの直接生成（[音変化再検討案](../音変化再検討案.md) §9）を語彙生成器のエンジンで計算し、曲用型は §9.4.1 で決めた。全語形を `辞書/morphology.js` で作り、ウェブ辞書の947項目の全語形と照合した（§3 末）。

**分布から読み取れること**

- 89項目すべてで、**単純語が最も多い型**である（54〜98%）。前提の語として加えた舅・姑（上位300の外）も、男から見た姑は単純語が38言語中18（47%）で過半数ではないが、複合8・句6より多い。
- 借用は最大でも41言語中7言語（タカ・塵・腎臓・ミミズなど）。政治語彙で使った古アルディア語からの文語借用の層は、基礎語彙には当てはまらないので使わない。
- 東語派固有の語根が44語と多い（辞書全体よりはるかに多い）。欠けていた項目は、アルディア語がまさに複合語（膝＝脚＋関節、ひげ＝顎＋毛、息子＝男＋子など）や借用語で埋めていた所か、語がない所である。WOLD の多数派は単純語なので、アルディア語の複合語を写さず、東語派が古い単純語を保っていたとする。既存の värd「首」（Ald. prōfebdepfli）、hran「髪」と同じ扱いである。

## 1. 決め方

| 観点 | 決め方 |
|---|---|
| **範囲** | WOLD の兼用の割合と CLICS⁴ の実例を目安にするが、割合の線引きでは決めない。実在の言語の語の範囲は、継承した語の古い範囲、その言語で起きた拡大・縮小、偶然の結び付きで決まり、多言語の平均にはならない。ラフカ語でも、多数派が分ける組を一語で兼ねたり、多数派が兼ねる組を分けたりする所を設けた（§2.2）。いずれも、どこかの言語で実際に起きている兼用・区別に限る。既存語の語義は広げない |
| **形** | その項目で最も多い型（89項目すべてで単純語）を基本にするが、一律にはしない。ラフカ語に関連する語があり、WOLD でもその作り方をする言語があるものは、既存語から作った（zepeden「唾を吐く」、perct「恐れ」）。zigla「闇」、vin「糸」からは作らない |
| **出どころ** | アルディア語に同じ意味の単純語があり、§9 でラフカ語の型に入るなら**継承**する。複合語・派生語・借用語・該当なし・型に入らない形（母音が残らない、など）なら**東語派固有の語根**を立てる |
| **継承語の範囲** | アルディア語の範囲を保つことも、狭めることもある（既存の enfeq は「舌・言語」のうち「言語」だけ、žäbepen は「触る・感じる」のうち「触る」だけを受け継いだ）。下表 |
| **曲用型・活用型** | 継承名詞は §9.4.1 に従う。強主格に短い a・e・o があればⅡ型、長母音・原生的な i・u・二重母音由来の母音なら固定型。動詞は短い a・e・o なら交替動詞、i・u・長母音なら非交替。固有の語根も同じ規則で祖形から決めた |
| **前提にされる語** | 作った語が体系の一部を前提にするなら、その語も作る。嫁・婿 → 舅・姑。「どれ」→ 相関詞の体系に置く |

| tlāfoch | タカ（ワシと区別しない） | タカ／ワシ 2/38（5%） | tlafoč「タカ」だけ。ワシは既存の gidal |
| wich | どれ（誰と区別しない） | どれ／誰 4/41（10%） | 継承しない。誰は既存の več、どれは wot・wotil（§3.10） |

## 2. 範囲の決定

**子の配偶者の総称は立てない。** WOLD で「子の配偶者」の総称を持つのは41言語中18言語だけなので、pald「婿」と sorna「嫁」で表す（pald de sorna「婿と嫁」）。配偶者のきょうだいの総称は41言語中25言語にあり、lirt を立てる。

## 5. 作者の判断が要る点

1. **範囲の選び方（§2.2）。** 多数派と違うラフカ語の兼用9組（高い・背が高い、生の・未熟な、熟した・煮えた、見つける・出会う、息子・男の子、硬い・難しい、膝・肘、盲目の・鈍い、へそ・真ん中）と、姑を夫の母 gelma・妻の母 šodra に分けること。ほかにどこを兼ね、どこを分けるかの希望があれば入れ替える。
2. **既存語から作った2語**：zepeden「唾を吐く」（zeped「唾」から）、perct「恐れ」（percten「恐れる」から）。
3. **東語派固有の語根44語の語形**（§3 の「固有」）。
4. **子の配偶者の総称を立てないこと**（§2.1）。
