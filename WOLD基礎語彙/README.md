# WOLD 基礎語彙リスト（控え）

2026-10-29 に、ラフカ語の基礎語彙を補う作業の材料として保存した。語彙の正本はウェブ辞書であり、このフォルダーの一覧は造語の対象を選ぶための参考資料である。

## 出典

- World Loanword Database（WOLD、Haspelmath & Tadmor 編）の「借用語類型論（Loanword Typology）」の意味リスト1,460項目。世界41言語の語彙調査に使われ、大陸間辞書シリーズ（IDS）の意味リストを拡張したもの。
- 取得元：CLDF 版 [lexibank/wold](https://github.com/lexibank/wold) の `cldf/parameters.csv`（2026-10-29 取得）。`Core_list` が yes の1,460項目だけを残した。寄稿者が個別に追加した354項目は除いた。

## 基礎度の算出

WOLD は意味ごとに、41言語の語の平均値として次の三つの数値を持つ。

- Borrowed_score：借用語である度合い（1に近いほど借用が多い）
- Age_score：語の古さ（1に近いほど古い）
- Simplicity_score：語の単純さ（1に近いほど分析できない単純語）

本一覧では **基礎度＝{(1 − Borrowed) ＋ Age ＋ Simplicity} ÷ 3** とし、高い順に並べた。Leipzig-Jakarta 100語の選定も同じ三つの数値を使っているが、各言語に対応語があるかどうかの指標も加えているため、順位は一致しない。

`WOLD意味リスト_基礎度順.csv` に全1,460項目を順位つきで収める。作業ではまず上位300項目（基礎度0.86以上）を扱い、ラフカ語との照合は [突き合わせ表_上位300.md](突き合わせ表_上位300.md)、欠けていた項目への造語案は、第1版 [造語案_上位300_第1版.md](造語案_上位300_第1版.md) を棄却し、41言語の分布から決め直した [第2版](造語案_上位300_第2版.md)（92項目、ウェブ辞書登録済み）に改めた。

## 使うときの注意

- WOLD の項目は**英語で立てた意味の区切り**であり、そのままラフカ語の見出しの単位にはしない。ある言語では一語が複数の項目を受け持ち、別の言語では一項目を複数の語に分ける。昔の日本語の「カク」が「書く・描く・掻く・欠く」を一語で表していたような例がそれに当たる。
- 一語がどの意味まで受け持つかは、アルディア語辞書の「区別しない」の注記（callen「動く」と「する」、cīh「昼間」と「日」、enfeg「舌」と「言語」など）、ラフカ語の既存語が持っている範囲、多言語の兼用例を集めた CLICS などで確かめてから決める。
- 番号に (1)(2) が付く項目（the child(1) / the child(2)、to ask(1) / to ask(2) など）は、WOLD が英語の一語を意味で分けたもの。
- 動植物は WOLD の調査言語の分布を反映しているので、ラフカの世界に存在するかを別に確かめる。
