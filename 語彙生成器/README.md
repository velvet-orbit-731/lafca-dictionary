# ラフカ語 同語根語生成器

[公開版を使う](https://velvet-orbit-731.github.io/lafca-dictionary/generator/)

公開版、または `python3 build.py` が書き出す `../generator/index.html` をブラウザーで開く。HTML 1 ファイルだけを移動しても動く。通信・インストール・サーバーは不要。

## 同語根語と祖語形を調べる

ラフカ語の見出し、またはアルディア語の登録された対応形を入力すると、ラフカ語の見出し・アルディア語欄・祖語形・語源注記を表示する。例えば `jure` / `juraj` は `*juraj`、`cori` / `kōri` は `*kōrī`。入力言語は「自動（両言語）」が既定で、同じ綴りが両言語にある場合は両方の一致を保持する。「ラフカ語」「アルディア語」で絞り込める。

登録祖語形はウェブ正本の `protoForms`、語源注記は各IDの `etymology` をそのまま表示する。複数形・強勢記号・再建仮説の注記を保持する。対応するアルディア語が未登録でも、ラフカ語見出しから祖語形を検索できる。非同源のアルディア語から別語根の祖語形へは結び付けず、ラフカ語見出し自身の検索ではその語自身の記載と非同源の注記を表示する。JSON保存にも祖語形・語源注記・出典を含める。

辞書の祖語形が空欄の語と、辞書にない新しい語は、規則から**祖語形の候補**を生成する。ラフカ語・アルディア語のどちらにも対応し、自動の場合は両言語の解釈を区別する。例：アルディア語 `rēdog` → `*rēdog` / `*reɣdog` など。ラフカ語の逆対応では `fäq` に `*fag-i` のような消失母音を含む案も作れる（登録祖語形がある場合は登録形を優先）。各候補の規則と入力への順方向照合を表示し、12件ずつページ分割する。JSON保存には全候補を含める。

祖語形が空欄でも語自体が登録されている場合は、**登録された曲用・活用の全語形と両立する候補だけ**を表示する。祖語候補から語幹と屈折形を導き、性・語幹類・交替型・母音の長短・ウムラウト・語末子音の交替まで照合する。例えば `bannen` は bann-/benn- と14語形に一致する `*bannen` を残し、交替できない `*bānnen` を除外する。`buq` は女性形 buga、中性形 büq などに合う *g の案を残す。候補ごとに照合結果を展開でき、JSONにも全語形の検査結果を含める。特殊な曲用などを説明できない場合は理由付きで保留する。

どちらの言語から登録項目へ到達しても、同じラフカ語見出しと登録された品詞・活用型を根拠に検査する。未知語用の選択条件でこの制約を変更しない。祖語候補は登録形を上書きせず、辞書へ保存しない。ラフカ語の屈折との一致だけから、アルディア語との共通祖形や継承・借用・後代の複合を確定しない。「自動」「アルディア語」で未知語なら、従来のラフカ語候補も併せて生成する。左側の長母音・短縮等の条件はこのラフカ語候補用。屈折形から見出しへの自動解析は行わない。詳しい規則・仮定・範囲は [祖語候補の生成](祖語候補の生成.md) を参照。

## 出力の意味

- **登録形**：Lafca2 の資料に明示された同語根対応。未知語用の変換で上書きしない。意味変化した同源語も含む。資料にない格形・活用形を自動で補完しない。
- **関連形・語根参照**：A/B 形や派生元として入力が記載されているもの。同じ語根の見出しを返すが、入力形からその見出しが直接音変化したとは扱わない。
- **候補**：音変化再検討案 §9 の有限な選択から得た形。採用・実在・同義性を確定しない。
- **祖語形の候補**：祖語と各語派の音対応を逆にたどった未採用の再建案。同じ規則で再建対象の語に戻ることを検査し、登録語なら曲用・活用とも照合する。
- **保留**：未定義の入力、音節調整が不足する屈折形、列挙上限など。保留があれば列挙完了とは表示しない。上限に達した場合は部分集合を破棄する。

「すべて」は、**選んだ条件と実装した有限規則の全経路**を指す。語義の変更、任意の類推、未定義の別読み、まだ作っていない派生語まで含む数学的な全集合ではない。資料自体の誤りを独立に証明・否定するものでもない。登録形と新語の候補を混同しないことで、根拠のない正解を出すことを防ぐ。

## 生成する範囲

| 項目 | 実装 |
|---|---|
| 辞書照合 | ウェブ正本 `dictionary.json` の全見出し・祖語形と明示的な Ald. 対応を取り込み。非同源は別枠。注記中の置換語を誤って別名登録しない |
| 子音 | 複文字を先に認識。sh/ch/c/k/pf/spf/sch、入力 p の p/pf 分岐。現代綴字は最後に適用 |
| 母音 | 長母音の単純対応/q 系列を位置ごとに列挙。短 i の固定/弱化系列、二重母音、aw/ew/aj 等の音節区切り |
| ウムラウト | 次音節の i/ī または音節頭 j。長母音は保護、q 系列は短母音に展開。弱化系列の i は引き金から外す |
| w/v | 語頭群の w を保護。前舌母音前・母音間・語末・子音前で v。変化前の母音間の情報を保持 |
| 語末母音 | 元からある短母音だけを対象とする。単音節・長母音/二重母音由来の母音を保持。脱落後の音節構造を検査 |
| 短縮 | 語頭または非初頭音節の短母音について、保持/音節制約に合う脱落を列挙。主格を保った斜格のみの短縮も含む。脱落期の無強勢は候補の仮定として表示 |
| 音節構造 | 最大 CCCVCCC、聞こえ度、s/š の語頭付加、語末 t/s、語末 sk、重子音、破擦音 pf/č/ž。音節境界の可能な分割を全検査 |
| 緩衝音 | 母音連続に j/w。子音間では、音節構造を満たす最少個数の e の挿入位置をすべて列挙 |
| g/q/k | 語幹 g を保存。裸形の母音後 q、n/r/l 後 k。長母音に対応させた q は屈折でも q |
| 名詞 | 未登録語の候補は男性・女性・中性、固定/Ⅰ/Ⅱ型の規則的な a/e・o/u・ü/u 系列。登録語は辞書の e/i、条件付き a/i、古いウムラウトや w/v を伴う斜格幹・曲用もそのまま表示する。中性は固定型。-a は女性、未登録の -e/-o は男性母音幹案 |
| 動詞 | 未登録の -en 子音幹。不定形・現在3単・アオリスト・現在1単・強弱語幹。短 i の4分析、u の固定/o-u/ü-u、a/e/o の交替または固定 |
| 形容詞 | 子音幹の男・女・中性形。入力 g と既存の q を区別 |
| 複数分析 | 同じ表記でも、曲用・活用・語幹・選択経路が異なる分析を保持。表記はページ分割し、JSON 出力には全結果を含める |

未登録の母音幹動詞、任意の縮約、既定と異なる á/ó 等の読み、未知の複合語の自動分解、接辞全体への不規則な類推、詳細が定まらない母音幹の全曲用は対象外。アルディア語の既知語根を含む未知の複合語・派生語は、語境界や派生方法を登録する必要がある。未知語の意味・品詞は綴りだけから推測しない。

短縮・交替・性をすべて選んだ結果は、単なる音対応の基本案より多い。例えば rēdog の基本的な二案は、名詞・男性・固定型・短縮なしで長母音を両系列にすると rädoq / reqdoq になる。条件を「すべて」に戻すと、中性化・交替型・斜格短縮などの分析も残る。

## ソースと更新

- `engine.js`：純粋な候補生成・登録照合。外部ライブラリなし。
- `proto.js` / `proto.test.js`：祖語候補の逆対応、順方向照合、言語ごとの分岐・上限・登録形保持の検査。
- `proto-paradigm.js` / `proto-paradigm.test.js`：祖語候補から導いた語幹と全登録語形の照合。`../辞書/morphology.js` の現代語の屈折規則を共有し、語形の例外上書きは使用しない。
- `build.py`：資料から辞書を取り込み、HTML を組み立てる。Python 標準ライブラリのみ。
- `data.json`：直下の `dictionary.json` から取り込んだ語彙・項目ID・資料の SHA-256。Git では管理せず、手編集せず再生成する。
- `shell.html` / `style.css` / `app.js`：画面。
- `engine.test.js`：資料照合、確定例、分岐の完全性、適用順、音節制約、入力拒否、成果物の同期確認。
- `ui.test.cjs`：任意の Playwright 環境で完成 HTML を開き、操作・全結果保存・モバイル表示・外部通信がないことを確認。ブラウザー検証用であり、HTML の実行には不要。

両ツールの再生成・検査は [保守ガイド](../保守ガイド.md) を参照。このフォルダーだけを確認する場合は次を実行する。

```sh
python3 build.py
python3 build.py --check
node --test engine.test.js proto.test.js proto-paradigm.test.js
```

公開版は `build.py` が書き出す `../generator/index.html` で、直接編集しない。検査後にコミットして push すると Pages に反映される。

新しい確定語はウェブ辞書（直下の `dictionary.json`）へ保存し、pull してから再ビルドする。生成した候補を画面操作だけで確定語として登録する機能は設けていない。HTML は生成時点のスナップショットであり、元資料を編集したら再ビルドが必要。

数詞 diwi / gewi / nīwi に対して div / gev / niv を中性・固定型の名詞型基数詞として登録し、辞書に明示された単複の五格を表示する。これは登録済みの対応・曲用の照合であり、未知語用の短母音脱落だけで語源を確定する機能ではない。乗算複合・加算数詞・序数の文法は親資料の7章を参照。Ald. 対応を未記載の複合語は同語根照合へ推測登録せず、任意の数値や数量文を組み立てる機能は設けていない。

ウェブ正本の全項目とID別のアルディア語対応注記を読む。語彙の正本はウェブ版だけで、ローカルMarkdownの辞書は使用しない。未採用案や会話例を自動登録しない。表示する語形はウェブ版に保存された全語形。

Ald. 欄の `<br>` は別の対応記述、括弧内の形は語根参照、〔派生・複合〕は直接の音対応と異なる語形成を表す。「非」は同語根として返さず、非同源欄へ出す。祖語・ラフカ語の派生元・注記中の借用語から Ald. の別名を推測しない。同じ綴りでも、動詞と小辞など品詞が異なる項目は保持する。

「状態」の採用済み／登録形はウェブ辞書に登録された項目を指す。fissačovin のような未採用案は照合対象に含めない。出典はウェブ辞書の項目IDと直接リンクで示す。

入力は NFC 正規化・小文字化・前後空白除去のみ。長音・ウムラウトを落とす近似検索はしない。画面に入力や辞書の文字列を挿入する際は textContent を用いる。外部スクリプト、外部フォント、解析送信、ネットワーク要求を使用しない。

複合語は古いものと新しいものを区別する。古い複合語は古い合成形全体への音対応、新しい複合語は現代の構成語による合成・再形成として扱い、登録形を本文どおり続け書きで表示する。両層とも曲用は通常どおり。fissačovin は新しい複合の未採用案である。便所の hlenqorn は Ald. awenaklohac と同義だが非同源なので、同語根の結果に含めず非同源欄に示す。統一辞書の「対応」が「非」の行は、明記された Ald. 同義語とともに非同源として取り込む。未知の複合語の層判定・自動分解・任意の縮約は行わず、資料に区分と語形を登録してから表示する。
