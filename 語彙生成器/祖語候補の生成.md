# 祖語候補の生成

2026-09-30、未登録の祖語形も両言語の入力から表示する作者の指定に対応。現代語の文法や公開辞書の祖語形は変更せず、未登録部分に有限な音対応モデルの再建候補を加える。歴史的な唯一解・採用済み語源として扱わない。

## 根拠と逆対応

言語規範は親の『ラフカ語文法』1.3–1.4。祖語音と中央語派との対応は『系統と設計ノート』2–4、相対年代は『音変化再検討案』2–3・6、綴字上の既定案は同9を参照する。設計ノートと再検討案の歴史仮説は、モデルの仮定として表示する。

| 入力 | 祖語候補 | 順方向の条件 |
|---|---|---|
| Ald. c / ch / sh / h / k | *ts / *tʃ / *š / *x / *k | 複文字を一音として処理 |
| Laf. ž / č / š / h / c・k | *ts / *tʃ / *š / *x / *k | k は語末、その他は c |
| Ald. p、Laf. pf | *p・*pw、*pf・*pw | *pw は中央語派 p、東語派 pf |
| Ald. ā ē ī ō ū | 同じ長母音、または短 a e i o u + *ɣ | 中央語派のɣ消失・代償延長を区別 |
| Laf. a ä i o ü | *ā ē ī ō ū など | 旧長母音はウムラウトしない |
| Laf. o ü e i ö | *aw ew aj ej oj など | 二重母音の単母音化 |
| Ald. au/ao/ó、ai/á、ei、oi/ø、ǖ | *aw、*aj、*ej、*oj、*ew | §9の綴字解釈を適用 |
| Laf. ä ö ü | 短 *a o u と後続 *i/ī/j、*aw と後続 *i/ī/j | 引き金を伴う場合だけウムラウト。後で脱落する *-i も可 |
| Ald. i、Laf. e/i | *ə を含む系列 | 前強勢弱化の仮説。後続の強勢音節を置ける位置に限る。Laf.では非語頭音節の š/ž/č 隣接時に i |
| Laf. q | *ɣ または語末 *g | *g は母音後で q、鼻音後で nk。語中 q は *ɣ |
| Laf. v / w | *w | 語頭子音群の保護、前舌母音前・母音間・子音前・語末の条件を照合 |
| 子音終わり | 語末母音なし、または脱落した短母音 | Laf. *-i/u/e/o、Ald. *-i/u。多音節・無強勢を仮定 |
| 動詞の -en | *-en | 品詞を動詞に指定した場合は不定形を保持 |

Ald.語末 -a は *a / *ā、語末 -i は *i / *ī の可能性を残す。後者は再検討案6.5の長形仮説を一般化した選択であり、すべての -i の起源を確定しない。母音間の Ald. v に *w を置く案も比較資料の語源仮説に依存する条件として明記する。前強勢 *ə の複数箇所への適用は、強勢位置が決められないため現モデルでは列挙しない。

## 照合と表示

入力の各音の逆対応を組み合わせ、祖語トークンへ変換する。ウムラウト→w/v→語末短母音の脱落→長母音・二重母音の反映→語末g→綴字の依存関係を保ち、入力へ戻る候補だけを表示する。内部では母音の由来・長短・子音wと二重母音を分け、現代ラフカ語の音節構造も確認する。保持系列では語末短母音の保持を仮定として添える。

登録祖語形があれば元の記載を優先する。空欄の登録項目では、どちらの言語から検索しても同じラフカ語見出し・品詞・性・曲用活用型・全登録語形を根拠に候補を絞る。検索条件で登録された品詞や交替型を変更しない。候補欄に再建対象のラフカ語見出しを明示する。

関連形・語根参照・非同源は、入力と見出しの共通祖形とは扱わない。ラフカ語の曲用・活用との一致は、アルディア語の対応形まで同一祖形から導けることの証明ではない。アルディア語の対応欄には異なる屈折形や派生語もあるため、両言語での語形成の同定は別途必要。古い複合語であるか、現代の派生語であるかも音対応だけでは決まらない。

「自動」の未知語は両言語を試し、同形でも言語別の分析を保持する。言語・品詞は指定可能。祖語候補と従来のラフカ語生成条件は独立し、辞書の語彙・ID・祖語形は変更しない。検索中の外部通信は行わない。

## 登録された曲用・活用との照合

`proto-paradigm.js` は候補の祖語トークンから語幹を導出し、文法に基づく `辞書/morphology.js` の規則で現代語の屈折形を生成する。正本の語形を予測値に流し込むことや、例外の上書き機能は使わない。生成した形と保存された全セルを比較し、一つでも不一致・未対応のセルがあればその分析を除外する。単数専用・複数専用、名詞型数詞、無主語、動名詞曲用の有無も保持する。主要形が足りない場合は検証済みとしない。

- 子音幹動詞：不定形 *-en から語幹を取り、交替型に合う母音階梯を導く。*a/ə、*e/i、*aj/i、*o/u、*aw/u と旧長母音を区別する。`bannen` は bann-/benn- と14語形を導ける `*bannen` を残し、交替できない `*bānnen` を除外する。
- 名詞：性・語幹類を制約にし、Ⅰ型は弱い主格から強い斜格、Ⅱ型は強い主格から弱い斜格を導く。長母音は階梯交替させない。中性子音幹の消失 *-i、女性 -a 幹の *-ā、男性 -o 幹の *-aw、長 *-ī を保つ中性 -i 幹を区別する。条件付きの弱母音と先行音節のウムラウトも照合する。`davara` は daver-、`habera` は häbir- が必要。
- 子音幹形容詞：男性見出しと、女性・中性、単複各格、登録された比較・派生形を照合する。`buq` は buga・büq 等から *g を持つ案を残し、*ɣ の案を除外する。
- 与格・中性形などのウムラウト：祖語の母音を保持して引き金 *i による語幹も導出する。現代形へ合流した旧 *ā・*ō を短母音扱いしてウムラウトさせない。例えば `bod` / `böd` に対し、類推を追加しない `*bōd` の案は除外する。

画面とJSONに、候補ごとの語幹・階梯の根拠・全登録語形と予測形・除外理由を含める。同じ祖語表記でも異なる階梯の起源なら分析を残す。曲用・活用表を持たない不変化語には「音対応のみ」と表示する。未知語には登録表との一致表示を付けない。

母音幹動詞・母音幹形容詞、特殊な曲用、短縮・補充・再編を必要とする語で整合する案を作れない場合は理由付きで保留する。一致しない表を変更したり、類推を自動で追加して候補を通したりしない。この検査は登録された現代語の曲用・活用との整合性を確認するもので、すべての語尾の歴史的な起源を確定するものではない。

## 範囲と計算上限

強勢は未指定で、階梯交替には文法で規定する格別・語幹別の強勢を仮定する。任意の消失した語中・語頭母音、ʔ消失後の縮約、緩衝音の除去、入力された屈折形からの見出し解析、未定義の階梯、語彙ごとの類推、借用、複合語境界・成立年代は自動確定しない。候補の存在は実在の祖語語彙の証拠ではない。

探索の既定上限は12,000段階。APIで `protoLimit` を指定した場合も上限50,000段階。上限を超えたら途中の候補を破棄して理由を表示する。候補のページ分割は列挙打ち切りではなく、JSONには全候補・入力言語・適用規則・順方向照合結果を保存する。
