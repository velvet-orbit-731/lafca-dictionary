# 同語根語生成器の保守

- 公開用の `../generator/index.html` と確認用の `data.json`（Git管理外）は `python3 build.py` の生成物。直接編集しない。
- 言語仕様は親フォルダーの `ラフカ語文法.md` を常に最優先し、語彙はリポジトリ直下の `dictionary.json` から読む。ローカル辞書Markdownを作成・参照しない。生成器の実装を理由に文法書を変更しない。文法書との不一致は辞書・実装側で修正し、文法書で規定された語形自体の変更には作者の指定が必要。
- 登録形、関連する語根への参照、新語の候補、未定義・保留を混同しない。未定義の規則を実装者の判断で確定扱いにしない。
- 同じ表面形でも、選択経路や語幹・活用型が異なれば分析を保持する。上限で途中まで列挙した集合を全候補と表示しない。
- 意味が一致する非同源行を同語根として登録しない。資料の注記中の借用語・置換語を、正規の対応語の別名として取り込まない。
- 変更後は再ビルドし、`node --test engine.test.js` を実行する。画面・ブラウザー動作を変更した場合は、利用できる Playwright 環境で `ui.test.cjs` も実行する。
- 外部ライブラリ・通信なしで HTML 単独実行できる性質を保つ。
