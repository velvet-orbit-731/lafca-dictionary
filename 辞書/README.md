# ラフカ語・分類辞書

[ウェブ辞書](https://velvet-orbit-731.github.io/lafca-dictionary/)をブラウザーで開く。検索・分類・活用表は HTML 一つで動作し、ページを保存すれば単独でも開ける。追加・編集・公開には、GitHubによる所有者認証が必要。

GitHub Pages版：[ラフカ語辞書](https://velvet-orbit-731.github.io/lafca-dictionary/)。公開先はラフカ語専用の [velvet-orbit-731/lafca-dictionary](https://github.com/velvet-orbit-731/lafca-dictionary)。

## 収録と使い方

- ウェブ版の `dictionary.json` が全項目の唯一の正本。表示用HTMLとローカル生成物は、この全語彙から生成する。
- 人名150語（男性122・女性28）を収録。借用人名46語、固有人名102語、ニュース原文の人名2語を共通の「人名」タグで検索でき、資料の性・語幹・確認済みの祖語型を保持する。固定型・単数のみの名詞として五格で曲用する。ニュース原文の Čino・Maltaman には未確認の祖語型を補わない。
- 規則的な「〜すること」だけを意味する動名詞は見出しにしない。独立した意味・用法を獲得した根拠があるものだけを語彙として収録する。原資料の「gessad 等」と、語彙化の根拠が確認できない `humad`・`sibad` は、元の動詞 `gassen`・`homen`・`seben` の語形として扱う。定型句中の一例だけでは、動名詞自体の語彙化とは認定しない。「u ＋ 与格」は前置詞 `u` の語義へ統合し、「zen pfor ＋ 動名詞」は慣用句 `zen pfor` として収録する。見出しや語形に説明用の日本語を混ぜない。非生産的な `-ča` と化石的な `-t-` は接辞として収録せず、`horča`・`tešten` などの個別語を保持する。
- 見出し語・訳語・全文から検索対象を選び、前方・部分・完全一致で検索できる。「変化形も探す」で活用・曲用形も対象にする。分類・祖語型は「全文」で検索。空白区切りはAND検索。ウムラウトやアクセントは常に区別する。同じ文字の合成済み表記と結合文字による表記は同一視する。
- 品詞は名詞・代名詞・動詞・形容詞・連体詞・副詞・前置詞・接続詞・小辞・間投詞の10種類。項目種別で単語・接辞・慣用句を選ぶ。数詞欄の「すべての数詞」で基数・序数の62項目をまとめて検索でき、「基数」「序数」でそれぞれに絞り込める。「指定なし」は数詞に限定しない。基数は名詞18語・形容詞1語・連体詞12語、序数は連体詞31語。11〜19と20〜90は一語の複合数詞として収録し（cwendegan「11」、swocven「20」、cwenindiv「70」）、百以上の倍と位をまたぐ加算は文法7章の生産的規則として扱い個々の数を登録しない。
- 性は名詞を選んだときだけ表示。分類は名詞・動詞・形容詞それぞれに適用するものだけを表示する。品詞を変えると、それまでの性・分類・タグの絞り込みを解除する。項目のタグを押すと品詞に合わせて絞り込める。基数・序数タグは品詞の条件を外して数詞全体を検索する。関連語を押すと派生元・派生語の詳細を開く。
- 「シャッフル」で現在の検索・分類条件を保って結果を並び替える。順番はページ移動後も維持し、「リセット」で辞書順に戻す。上部・下部のページ番号から先頭・近隣・中間・末尾へ直接移動できる。
- 動詞と動詞慣用句は「活用」、それ以外の屈折語は「曲用」で表を表示。表外の語形プレビューや原資料の注記は表示しない。明示された祖語型がある項目だけ「祖語型：*…」の書式で表示する。
- `-aq` 派生17語を名詞として分類し、ウェブ辞書の各項目に従って固定の子音幹で曲用する。名詞由来の性は継承、形容詞・動詞由来は資料の既定の男性。民族名由来の `inzaq`・`šewaq` は人を指す男性名詞。`čaq` は文法で定める代名詞の六格、動名詞の曲用は元の動詞の語形表内に収録し、変化形検索から引ける。

| 品詞 | 分類 | 表示する語形 |
|---|---|---|
| 名詞 | 男・女・中性、固定・Ⅰ・Ⅱ・不規則、語幹末の種類 | 五格×単複。単数のみ・複数のみの制限を反映 |
| 動詞 | a/e・e/i・o/u交替、非交替、母音幹、不規則 | 現在人称、アオリスト、命令、接続・条件法、動名詞、過去分詞 |
| 形容詞 | 子音・母音幹、中性ウムラウト・男中同形、語幹短縮、語末子音交替 | 性×数×五格、比較級・最上級・副詞形 |
| 基数の名詞（div・cwen・swocven 系） | 名詞・基数・固定型（žamra は女性、他は中性） | 登録済みの五格×単複 |
| 基数の形容詞（gan） | 形容詞・基数 | 性×数×五格。比較級・最上級・副詞形は作らない |
| 連体詞 | 基数・序数など | 不変化 |

形容詞のタグは現行文法を説明するための閲覧上の分類。名詞の固定・Ⅰ・Ⅱ型を形容詞に拡張したものではない。不規則性と母音幹・交替型は独立した情報なので、len は母音幹＋不規則、tanen はa/e交替＋不規則を併記する。

## 内部データの語形の根拠

語源・アルディア語対応等の設計注記はウェブ正本の `metadata` に保持する。閲覧用HTMLにはそれらの注記を出力せず、分類タグ・訳語・祖語型・語形・関連語を収録する。

語形表はウェブに保存された形をそのまま読み込む。再生成時に別資料の語幹や明記形で上書きしない。ウェブ編集画面で補完した場合も、公開時に確定した語形を正本へ保存する。

語形の欠落や名詞の性の未指定は生成時にエラーとする。存在しない数・人称・命令形は表の欄を作らず、検索にも含めない。

固定型でも与格ウムラウトやq/g交替は起こる。qを一律にgへ置換せず、本来の*ɣと*g起源を区別する。manča・bidašta・höri は男性・複数のみの独立名詞として五格を表示し、manž・bidiš・hor から関連語で参照する。lona・fatta は女性のまま単数・複数を持つ。正本に不可算・単数のみと記した198語（人名150語を含む）は「複数形なし」と表示し、単数の五格だけを収録する。無主語のdeqenは現在diqの一形だけを表示し、1・2人称・複数・命令形を生成しない。

短語尾母音幹は文法2.1.5、母音幹動詞は2.3.2・2.3.5–2.3.6、子音接合は1.4に従う。収録の一覧は [収録情報](収録と未確定事項.md)。関連語は資料と作者の指定に従う。画面で保存された関連語も `dictionary.json` に保持する。

## 画面からの追加・編集

意味欄は1行に1語義を入力する。複数の語義は番号付きで別々に表示する。同じ語義の訳語は `,` と `、` のどちらでも区切れ、表示と保存時には `, ` に統一する。各行のどの訳語でも完全一致検索で引ける。たとえば amla は1行目を「荒野, 曠野」、2行目を「空虚, 虚無, 空っぽ」とする。

同義語・漢字・かなの表記違いも訳語として登録する。人名の性別などの括弧注記や、訳語の前後の「〜」を入力しなくても検索できる。全項目の点検記録は `meaning-review.json` に残すが、その後の所有者の編集をこの記録で上書きしない。

上部の「所有者ログイン」で所有者のGitHubトークンを入力すると、編集用のボタンを表示する。「語彙を追加」または各項目の「編集」「複製して追加」を押し、見出し、品詞、性、分類、数の制限、意味、祖語型、タグ、語形、関連語を編集する。活用・曲用は見出し・性・分類・語幹から自動補完し、入力を変えると語形表も更新する。Ⅰ・Ⅱ型などの斜格幹、語末qの交替、母音幹動詞の不規則な現在語幹は必要に応じて指定する。短語尾と緩衝子音型、-aq派生語、複数のみの曲用も選べる。複数形なし・無主語などの制限を反映し、基数の形容詞には比較級を作らない。個別の語形を直すとその例外を保持し、「自動」で補完形に戻せる。語形を削除した場合は再補完でも復活させない。

タグは品詞・項目種別、性、変化型・語幹、数の制限、数詞などの機能、人名・追加タグの順に表示する。品詞・性・分類・語幹・数の設定から決まるタグは自動で付き、「追加タグ」には人名などをカンマまたは読点で入力する。古い下書きやバックアップでも表記・順序・重複を同じ規則で整理する。

関連語の関係は「派生・類義・対義」から選ぶ。「派生語」「派生元」は「派生」に統一し、旧下書き・バックアップも読み込み時に変換する。見出し語・日本語の意味を入力すると候補を絞り込む。候補の品詞・意味で同綴りの語を区別でき、クリックまたは上下キー＋Enterで選択する。ウムラウトを区別し、選択した語のIDでリンクを保存する。公開した関連語はログインせずに閲覧でき、相互リンクもログイン状態に関係なく補完する。

派生・類義・対義・集合名詞の関連は、ウェブ正本の各項目に保存する。別の派生表から上書きしない。

「保存して公開…」で未公開の変更一覧を開き、「公開する」でGitHubへ保存する。端末だけに残す場合は「下書きに保存」を選ぶ。既存の下書きは上部の「未公開の変更を公開…」から公開できる。編集画面の「単語を削除」で削除を登録し、「公開する」で反映する。削除した語への関連リンクも整理する。公開前なら変更一覧の「変更を取り消す」で元に戻せる。公開後は別の端末からも同じ辞書を閲覧できる。GitHub Pagesの反映には少し時間がかかる。ブラウザーの保存データを消す前や別の端末へ未公開の変更を移す場合は「変更をバックアップ」を使い、「変更を読み込む」で復元する。補完の設定と手入力した例外も保存・復元される。

編集できるのは所有者 `velvet-orbit-731`（GitHubユーザーID `337917858`）のみ。GitHubの認証済みユーザーAPIと専用リポジトリの所有者・編集権限を確認して編集画面を開き、公開保存のたびに再確認する。第三者による公開ファイルの変更はGitHub側のリポジトリ権限で拒否される。共同編集者・書き込み用デプロイキーを追加しない。

所有者ログインには、この専用リポジトリだけを対象にしたfine-grained personal access tokenを使う。必要な権限はContentsのRead and write。作成リンクはログイン画面にある。トークンをチャットや辞書データへ記載しない。トークンはそのページのメモリー内だけで保持し、入力欄・ブラウザーの保存領域・バックアップ・公開データに残さない。「編集を終了」またはページを移動すると破棄し、再読み込み後は再認証する。未公開の下書きは端末に保持し、所有者が再認証した後で復元する。[GitHub公式のトークン管理](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)を参照。

保存時は最新mainを読み、別の語の変更を統合する。同じ語が他の端末で更新されていたら上書きを止める。削除は下書きの after:null と公開版 dictionary.json の deletedIds で保持し、再生成時にも適用する。HTML・dictionary.json・version.jsonは一つのコミットにまとめ、mainを強制更新しない。通信失敗時は端末の変更を保持する。途中で応答が失われた場合も再保存できる。

## 保守・書き出し

語彙の唯一の正本はリポジトリ直下の `dictionary.json`。`python3 build.py` がこのフォルダーに確認用の HTML・`data.json`・収録一覧を生成し、`python3 export_pages.py` が公開用の `../index.html`・`../version.json`・`../収録と未確定事項.md` を更新する。どれも生成物なので直接編集しない。

文法の配布形式はMarkdownのみ。辞書と生成器の再生成・検査、ソースの構成、保存済み編集を引き継ぐ公開用書き出しは [保守ガイド](../保守ガイド.md) にまとめる。語形の収録範囲は [収録と未確定事項](../収録と未確定事項.md) を参照。
